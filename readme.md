# 数据结构基础 · 刷题清单与教学

> **目标**：用最少的题量，把 C++ 六个基础数据结构的 **语法** 和 **常用函数** 练成肌肉记忆。
> **不涉及**：复杂算法（没有动态规划、没有单调栈、没有二分答案、没有数学技巧）。
> **只做简单题**，但把简单题再细分成三级，让难度坡度尽量平缓。

## 怎么用（建议顺序）

```
① 读教学第 N 章的「函数表」   ← 每章第一节，四列：函数体 / 参数含义 / 用法例子 / 例子说明
② 读教学第 N 章的正文（概念 + 套路 + 坑 + 自测）
③ 刷清单第 N 章的题，从 ⭐ 开始一级一级往上
④ 卡住了 → 回教学看「刷题套路」和「常见坑」
⑤ 一章刷完 → 换下一章
```

**不要跳章**：数组 → 字符串 → 哈希表 → 链表 → 栈 → 队列，后一章都建立在前一章的基础上。

## 分级说明

题目全部是力扣「简单」难度，但简单题之间的认知负荷差别很大，所以再细分三级：

| 级别 | 含义 | 单题目标耗时 |
|---|---|---|
| ⭐ | **入门**：一个动作（遍历 / 取值 / 构造），一个变量就够 | ≤ 3 分钟 |
| ⭐⭐ | **基础**：一个套路（计数 / 累加 / 判断 / 简单映射） | 3–6 分钟 |
| ⭐⭐⭐ | **稍难**：两个基础动作组合，或要处理一个明确的小边界 | 6–10 分钟 |

**升级判据**：同一级的题能一次 AC、不用试错 → 进入下一级；做着别扭 → 同级再练。

## 函数表格式

每章第一节都是一张四列表，格式统一：

| 函数体 | 函数体内的参数含义 | 使用例子 | 例子的参数含义 |
|---|---|---|---|
| `vector<A> B` | A 指元素类型，B 指变量名称 | `vector<int> v` | 创建一个名为 `v` 的空数组，元素类型为 `int` |

- **第一列**：函数/类型的"模板写法"，用 A、B、C 当占位符
- **第二列**：这些占位符分别代表什么
- **第三列**：一个能直接抄进代码的具体例子
- **第四列**：这个例子在做什么（把参数也解释出来）

## 学习节奏建议

1. **一天一章**，8–10 题一次做完（同章知识点重复度最高，最容易形成肌肉记忆）
2. 每题写完，**对着函数表确认**：用到的函数表里都有吗？没有就说明超纲了，先跳过
3. **卡住 15 分钟就看题解**，看完关掉题解**默写**一遍
4. 每章做完，合上文档把「本章用到的函数」自己复述一遍 —— 这才是本册的真正目标
5. 全部刷完后，回来看每章的「常见坑」表，把踩过的再标一遍
