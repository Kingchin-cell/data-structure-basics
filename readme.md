## 怎么用（建议顺序）

```

  ① 读教学第 N 章的「函数表」（每章第一节）
  ② 读正文（概念 + 套路 + 坑 + 自测）

  ④ 卡住了 → 回教学看「刷题套路」和「常见坑」

  二叉树（第 1-2 章）→ 双指针（第 3 章）→ 滑动窗口（第 4 章）→ 二分（第 5 章）→ 排序贪心（第 6 章）
```

- 第二部：**先把二叉树的递归练熟**，再学双指针 / 滑窗（后者都是迭代，会简单一些）

## 函数表格式

两部的每章第一节都是**四列函数表**，格式统一：

| 函数体 | 函数体内的参数含义 | 使用例子 | 例子的参数含义 |
|---|---|---|---|
| `vector<A> B` | A 指元素类型，B 指变量名称 | `vector<int> v` | 创建一个名为 `v` 的空数组，元素类型为 `int` |

- **第一列**：函数 / 类型的"模板写法"，用 A、B、C 当占位符
- **第二列**：这些占位符分别代表什么
- **第三列**：一个能直接抄进代码的具体例子
- **第四列**：这个例子在做什么（把参数也解释出来）

**共 172 条**（第一部 106 + 第二部 66），覆盖两套清单里用到的每一个函数。

## 学习节奏建议

1. **一天一章**，8–10 题一次做完（同章知识点重复度最高，最容易形成肌肉记忆）
2. **每题写完，对着函数表确认**：用到的函数表里都有吗？没有就说明超纲了，先跳过
3. **卡住 15 分钟就看题解**，看完关掉题解**默写**一遍
4. **二叉树一定要画图**：递归题不画树，全靠脑补必错
5. 每章做完，合上文档把「本章用到的函数 / 套路」自己复述一遍 —— 这才是本册的真正目标
6. 全部刷完后，回来看每章的「常见坑」表，把踩过的再标一遍
